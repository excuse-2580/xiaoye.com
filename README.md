# 炭与黎的工坊 · 小夜的主页

## 📂 文件说明
- `index.html` — 主页面（含 SEO 关键词 + 成分分析）
- `robots.txt` — 告诉搜索引擎「允许抓取」
- `sitemap.xml` — 站点地图（提交给 Google/Bing/百度）
- `README.md` — 本文件

## 🚀 部署（GitHub Pages）
1. 把这 4 个文件**放到仓库根目录**
2. 等 1-2 分钟，访问 `https://excuse-2580.github.io/` 查看

## 🔍 让搜索引擎收录（SEO）
1. 去 Google Search Console 验证 `excuse-2580.github.io` → 提交 `sitemap.xml`
2. 去 Bing Webmaster 同理
3. 在 B站 / 抖音 / QQ空间 / 兽频道简介里贴上主站链接（外链很重要！）
